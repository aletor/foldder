FOLDDER

Guía de nodos — Qué puedes crear y cómo combinarlos

FOLDDER organiza tu trabajo creativo como un lienzo visual: cada bloque es un nodo (texto, imagen, vídeo, diseño, datos…) y las flechas conectan la salida de uno con la entrada del siguiente. Muchos nodos abren un Studio a pantalla completa con herramientas avanzadas; otros se usan directamente en la tarjeta del lienzo.

Antes de empezar

  • Conectar nodos: arrastra desde un punto de salida (derecha) hacia un punto de entrada (izquierda) del nodo destino.
  • Abrir Studio: pulsa el botón central del nodo o haz doble clic en nodos con panel propio.
  • BrandKit: identidad del proyecto (logo, colores, tono). Conéctalo a diseño, textos e imágenes para mantener coherencia.
  • Dataset: tabla con filas (productos, personas, variantes…) y datos fijos compartidos. Base de personalización masiva.
  • Lista de medios: paquete de imágenes y vídeos listos para exportar o montar en secuencia.
Flujo típico de campaña
BrandKit → Dataset → Designer (plantilla) → Loop o Populate → Export Multimedia

Flujo audiovisual
Guionista → Cine → Image Creation → Video Creation → Video Editor

1. Producción principal

Núcleo para campañas, contenido editorial y piezas audiovisuales completas.

BrandKit Studio

Centro de identidad del proyecto: logo, colores, documentos de referencia y tono de marca. No genera piezas por sí solo, pero alimenta casi todo lo demás.

Ideal para: mantener la misma identidad en diseños, guiones e imágenes; actualizar el logo una vez y que se refleje en todos los diseños enlazados.
Conecta con: Designer, Guionista, Cine, Image Creation, Dataset.
Guionista Studio

Convierte ideas en textos listos para publicar o rodar: posts, artículos, guiones, escenas, slides, campañas o reescrituras. Genera varias versiones y enfoques editoriales.

Ideal para: redactar con tono de marca, preparar guiones para vídeo, estructurar presentaciones.
Conecta con: Cine (preproducción), Prompt e Image Creation (texto para generar).
Cine Studio

Preproducción audiovisual completa: a partir de un guion obtienes personajes, fondos, escenas, storyboard, imágenes de referencia y plan de vídeo. Todo se empaqueta en una lista de medios.

Ideal para: spots, fashion films, vídeos de producto, contenido social con storyboard previo.
Modos: cortometraje, publicidad, moda, documental, producto, videoclip, marca, social.
Conecta con: Image Creation, Video Creation, Export Multimedia, Video Editor.
Designer Studio

Estudio de diseño multipágina: texto, imágenes, formas y maquetación profesional. Puedes crear catálogos, posts, packaging, slides imprimibles o plantillas reutilizables.

Ideal para: piezas gráficas con varias páginas; plantillas que se rellenan con datos; recibir capas de una foto descompuesta (Layerizer).
Conecta con: Presenter (presentación), Populate y Loop (personalización), Export Multimedia.
Image Creation Studio

Genera y edita imágenes con inteligencia artificial: desde cero con una descripción, o partiendo de hasta cuatro imágenes de referencia (estilo, composición, retrato…).

Ideal para: creatividades, variaciones de producto, retratos, escenas para vídeo, iteraciones rápidas.
Conecta con: Inspiration (referencias), Crop, Background Removal, Layerizer, Video Creation, Export.
Video Creation Studio

Genera vídeos con IA a partir de un prompt, de una imagen inicial, o animando entre dos imágenes (inicio y fin). Incluye presets de cámara, estilo e iluminación.

Ideal para: clips cortos para redes, animar frames de Cine o Image Creation, motion sobre una imagen fija.
Nota: el servicio puede rechazar ciertos contenidos por sus políticas de seguridad (personas, marcas, contenido sensible). En ese caso prueba otra imagen o un prompt más neutro.
Conecta con: Video Editor, Export Multimedia, VFX Generator.
Presenter Studio

Convierte un diseño multipágina de Designer en presentación interactiva: animaciones por pasos, transiciones entre slides y posibilidad de colocar vídeos sobre imágenes. Enlaces para compartir.

Ideal para: pitch decks, presentaciones de campaña, portfolios animados.
Requiere: un Designer conectado con documento multipágina.
Video Editor Studio

Montaje en línea de tiempo: une varios vídeos o importa una lista de medios completa. Pistas de vídeo y audio, subtítulos automáticos y render final.

Ideal para: pieza final de campaña, secuencia de clips generados en Cine o Loop, montaje con subtítulos.
Conecta con: salida de Cine, Loop, Populate o Export Multimedia.

2. Datos y personalización

Automatiza la producción de muchas piezas distintas a partir de una tabla de datos.

Dataset Studio

Tabla del proyecto con filas (cada fila = un producto, persona, variante…) y constantes compartidas (legal, URL, tagline). Es la fuente de datos para personalizar diseños e imágenes.

Ideal para: catálogos, campañas con muchas variantes, datos que cambian pero la plantilla se mantiene.
Conecta con: Loop, Populate, Designer.
Loop Studio

Produce una pieza por cada fila del Dataset usando una plantilla conectada (Image Creation o Designer). Ejecuta todo el lote de forma automática y entrega una lista de medios.

Ideal para: 50 posts distintos, 100 tarjetas de producto, variaciones masivas sin intervención manual.
Ejemplo: Dataset (productos) + Designer (plantilla) → Loop → Export Multimedia.
Populate Studio

Personalización guiada por persona: conectas plantillas Designer y un Dataset; cada usuario elige sus datos y genera su pieza mediante un formulario público (enlace compartible).

Ideal para: eventos, merchandising personalizado, campañas UGC, tarjetas con nombre y foto del asistente.
Diferencia con Loop: Loop = todas las filas automáticamente; Populate = cada persona elige qué generar.
Formulario público: enlace tipo foldder.com/f/… con preview antes de generar.

3. Texto e ideas

Prompt Lienzo

Campo de texto libre que alimenta generadores de imagen, vídeo o Guionista. Puedes ponerle un título visible («Estilo», «Color de ojos»…).

Notes Lienzo

Nota adhesiva con texto enriquecido. Útil para briefings, restricciones o contexto que luego conectas a otros nodos.

Concat Lienzo

Junta varios textos en uno solo (sin IA). Por ejemplo: Prompt + Notes + salida de Guionista → un único prompt para Image Creation.

Enhance Lienzo

Mejora un prompt breve convirtiéndolo en una descripción detallada lista para generar imágenes o vídeos.

Image Describer Lienzo

Mira una imagen y escribe qué contiene. Útil para «copiar el estilo» de una referencia en texto y luego generar algo similar.

Inspiration Studio

Busca referencias visuales con licencia (Pexels, Unsplash, Are.na) a partir de una idea o de una imagen conectada. También puedes pegar un enlace directo a una imagen.

Ideal para: moodboards, buscar estilo antes de generar, encontrar texturas o paletas.
Conecta con: Image Creation, Layerizer, Crop.

4. Imagen — edición y preparación

Image Advanced Studio

Edición por capas sobre una imagen base que no se pierde: cada corrección se apunta y puedes iterar sin destruir el original.

Ideal para: revisiones con cliente, muchas iteraciones sobre la misma foto base.
Layerizer Lienzo

Descompone una foto compuesta en capas separadas (personas, objetos, texto…) y las envía a Designer listas para reordenar. También puede limpiar el fondo.

Ideal para: fotomontajes, catálogos a partir de una imagen compuesta, recomposición en Designer.
BG Removal Lienzo

Quita el fondo de retratos y personas, dejando PNG transparente. Ajustes de suavizado y expansión del recorte.

Crop Lienzo

Recorta y reencuadra imágenes (libre, cuadrado, horizontal 16:9, vertical 9:16 para Stories).

Painter Studio

Lienzo de dibujo libre: bocetos, anotaciones o máscaras manuales para efectos visuales.

Lightroom Studio

Revelado de fotos RAW en el navegador: exposición, curvas, color, máscaras locales y recorte. Sin IA — flujo fotográfico clásico.

Ideal para: fotógrafos que quieren revelar RAW antes de diseñar o generar sobre la imagen.

5. Vídeo — opciones adicionales

VFX Generator Studio

Aplica efectos visuales generativos sobre un vídeo existente, con prompt e imagen de referencia opcional.

6. Exportación y archivos

Export Multimedia Studio

Recibe listas de medios de Cine, Loop o Populate: revisa en rejilla, filtra, descarga todo ordenado o exporta un manifiesto.

Export Lienzo

Descarga una pieza concreta: PNG/JPG (imagen), PDF multipágina (Designer) o MP4 (vídeo).

Foldder (Assets) Lienzo

Acceso al inventario de medios del proyecto: todo lo importado, generado y exportado. Misma función que el icono Foldder de la barra inferior.

7. Organización del lienzo

Nested Space

Sub-lienzo dentro del proyecto: agrupa un pipeline en un módulo reutilizable. Puedes «entrar» y salir como si fuera otra pantalla.

Ideal para: campañas complejas, separar fases (concepto / producción / export), recibir resultados de Loop organizados.
Grupo de nodos

Marco visual para agrupar bloques del lienzo (atajo G). Solo organización — no ejecuta nada por sí solo.

8. Combinaciones recomendadas

Objetivo Recorrido sugerido
Catálogo de productos (muchas piezas) BrandKit → Dataset → Designer (plantilla) → Loop → Export Multimedia
Tarjeta personalizada por asistente BrandKit → Dataset → Designer → Populate → formulario público
Spot con storyboard Guionista → Cine → Image Creation → Video Creation → Video Editor
Presentación de campaña Designer → Presenter → (opcional) Video Creation desde slides
Desde foto compuesta a diseño editable Inspiration o Media → Layerizer → Designer → Export
Retrato para redes Media → BG Removal → Enhance + Prompt → Image Creation → Crop → Export
Fotografía RAW profesional Lightroom → Crop → Designer o Image Creation → Export
Referencias antes de generar Inspiration → Image Creation → Video Creation
